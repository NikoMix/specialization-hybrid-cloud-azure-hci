## What the Auditor Checks

The auditor verifies that your organisation has the spec-required number of individuals holding the **required Azure infrastructure certifications**, with each certification on the list held by at least one individual.

**Typical questions:**
- Can you provide verification links or transcripts for each certified individual?
- Are all certifications currently active (not expired)?
- Do the individuals work for your organisation (not contractors)?

## Required Certifications (verify against spec)

| Certification | Exam Code(s) | Minimum Holders (verify) |
|---|---|---|
| **Windows Server Hybrid Administrator Associate** | AZ-800 + AZ-801 | ≥ 1 (badge) |
| **Azure Administrator Associate** | AZ-104 | ≥ 1 |
| **Azure Solutions Architect Expert** | AZ-305 | ≥ 1 |

{{% alert type="note" %}}
The total minimum number of **unique individuals** (e.g. 4 or 5) and the exact cert list above
must be confirmed against the spec PDF. Typical Infrastructure-track Advanced Specializations
require a small team of holders, with no single individual able to cover all required certs by
themselves.
{{% /alert %}}

## Certification Validity

| Certification | Exam | Renewal Method | Renewal Window |
|---|---|---|---|
| Windows Server Hybrid Administrator Associate | AZ-800, AZ-801 | Free online renewal assessment on Microsoft Learn (per exam) | 6 months before expiry |
| Azure Administrator Associate | AZ-104 | Free online renewal assessment | 6 months before expiry |
| Azure Solutions Architect Expert | AZ-305 | Free online renewal assessment | 6 months before expiry |

{{% alert type="caution" %}}
Certifications must be **active at the time of audit**. Check expiry dates now and schedule
renewal assessments for anyone expiring within 3 months.
{{% /alert %}}

## Common Gaps

| Gap | Remediation |
|---|---|
| AZ-801 missing (the harder of the Windows Server Hybrid pair) | Prioritise scheduling this exam — most Windows admins find AZ-800 easier and AZ-801 the gating exam |
| Certifications held by contractors, not employees | Confirm employment status; some auditors accept long-term contractors with a letter from HR |
| Expired certifications | Complete the free Microsoft Learn renewal assessment immediately |
| Transcripts set to private | Instruct individuals to set their Learn profile to public or export a PDF transcript |
| Only one individual holds all certs | Spec usually requires multiple unique individuals — schedule exams for additional team members |
