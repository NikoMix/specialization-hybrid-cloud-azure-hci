## When to use this

Drafted at build kickoff, executed across build + hypercare. KT done late
is KT done badly — every audit-strong handover starts in week 1.

<Aside type="tip" title="Download the workfile">
  [📄 Download `kt-plan-template.docx`](${import.meta.env.BASE_URL}templates/deliverables/kt-plan-template.docx)

## Inputs you need from the customer

| # | Input | Source | Format |
|---|---|---|---|
| 1 | Ops team org chart + roles | Ops lead | Document |
| 2 | Existing skills baseline (AZ-104, AZ-800, AZ-801) | HR / L&amp;D | Table |
| 3 | Preferred KT cadence (weekly / bi-weekly) | Ops lead | Schedule |
| 4 | Recording &amp; documentation policy | Customer IT | Document |

## Default session catalogue

| # | Session | Audience | Duration | Proof point |
|---|---|---|---|---|
| 1 | Azure Local architecture overview | Ops + leads | 60m | Drawn-on-board diagram |
| 2 | Cluster build walk-through | Build engineers | 120m | Shadowed deploy step |
| 3 | Network ATC deep-dive | Network ops | 90m | Inspect ATC intent |
| 4 | Storage Spaces Direct ops | Storage ops | 90m | Run capacity report |
| 5 | Arc enrolment &amp; RBAC | Cloud ops | 60m | Assign a new role |
| 6 | Monitoring &amp; alert response | NOC | 90m | Triage a synthetic alert |
| 7 | Patching cycle | Patch team | 60m | Execute patch under supervision |
| 8 | Backup &amp; restore | Backup team | 60m | Restore a test VM |
| 9 | Stretch / DR drill | DR team | 120m | Trigger failover + failback |
| 10 | Day-2 runbook walkthrough | All ops | 90m | Sign-off runbook |

## Step-by-step

<Steps>
1. Confirm the session catalogue with the customer ops lead at kickoff.
2. Schedule sessions across build + hypercare; do not back-load to the
   final week.
3. Capture attendance + proof-point completion per session.
4. Customer ops lead signs each completed session.
5. Final sign-off feeds Definition of Done.
</Steps>

## Reuse &amp; contribute back

<Aside type="tip">
  If a customer needed an extra session (e.g. AVD on Azure Local, GPU
  partitioning), promote it into the default catalogue via PR.
</Aside>
